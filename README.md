# Controlix AI

Autonomous SIEM / SOC. This repository holds the public website and the installer; the product ships as
Docker images and a release bundle, the source code is not published.

Install (on your Linux server, with its own IP address or DNS name):

    curl -fsSL https://abdemadjid.github.io/controlix/install.sh | sudo sh -s -- install --host YOUR_SERVER_IP

Documentation: https://abdemadjid.github.io/controlix
